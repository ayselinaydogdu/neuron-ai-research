# AI Feature Glossary / AI Özellik Sözlüğü

## English

A shared vocabulary so reviews stay consistent. For each site, note whether each
item is **present / partial / absent**.

### Search
- **Natural Language Search:** Free-sentence queries like "3-bed under £300k near
  schools" — intent interpretation instead of raw filters.
- **Smart Suggestions / Query Understanding:** Handling typos/synonyms, smart
  narrowing when there are many results, personalised ranking.
- **Saved Search / Alerts:** Automatic listing notifications by criteria (e.g.
  "Heads Up Alerts").

### Listing Detail
- **Property Summary (AI):** AI summary reducing a long description to 2–3 points.
- **Property Q&A:** Free-form questions about a listing ("is it suitable for a family?").
- **Property Highlights:** AI-extracted standout points of the listing.
- **Lifestyle / "Ideal for…" Matching:** Fit commentary based on lifestyle.
- **Property Comparison:** AI comparison of two or more listings.
- **Similar Listings (personalised):** Behaviour-based "you might also like".
- **Area Insights:** Neighbourhood data (schools, crime, demographics) with AI commentary.
- **Commute Insights:** Travel time to work/school with commentary.
- **Document Explanation (EPC / Floor Plan):** AI explaining EPC and floor plans in plain language.

### Valuation
- **Instant Valuation:** Immediate estimated value (not just a "we'll call you" form).
- **AI Valuation Explanation:** Explaining/personalising what the number is based on.
- **Mortgage / Stamp Duty Calculator:** Is a calculator present; does it only show a
  number, or is there **AI financial commentary/advice** too?

### Contact / Lead
- **AI Chat Assistant / Chatbot:** Site-wide or listing-level chat assistant.
- **Lead Qualification:** Same generic form for everyone, or AI pre-screening/prioritising?
- **Automated Booking / Viewing Scheduling:** AI-driven viewing/appointment setup.
- **Out-of-hours Response:** Any auto-reply/chatbot out of hours, or silence?

### Technical / General
- **SSR vs CSR:** Server-rendered (Nuxt/Next SSR) or client-side?
- **API calls:** Does the Network tab show the Neuron API or third-party services?
- **Mobile behaviour:** Are filters/forms usable on mobile?

> Rule: Even when a feature appears "present", note **how well** it works
> (e.g. the AI chat answers simple questions but defers to an agent on detail).

## Türkçe

İncelemelerde tutarlı olmak için ortak terim seti. Bir sitede bunlardan hangisi
**var / kısmen var / yok** olduğunu not edin.

### Arama
- **Doğal Dil Araması (Natural Language Search):** "okula yakın, £300k altı 3+1
  ev" gibi serbest cümleyle arama. Filtre yerine niyet yorumlama.
- **Akıllı Öneri / Sorgu Yorumlama:** Yazım hatasını/eş anlamı anlama, sonuç
  çoksa akıllı daraltma, kişiye göre sıralama.
- **Kayıtlı Arama / Alerts:** Kriterlere göre otomatik ilan bildirimi (ör. "Heads
  Up Alerts").

### İlan Detay
- **Property Summary (AI Özet):** Uzun açıklamayı 2–3 maddeye indiren AI özeti.
- **Property Q&A:** İlan hakkında serbest soru sorma ("aile için uygun mu?").
- **Property Highlights:** İlanın öne çıkan yönlerini AI'nin çıkarması.
- **Lifestyle / "Ideal for…" Eşleştirme:** Yaşam tarzına göre uygunluk yorumu.
- **Property Comparison:** İki+ ilanı AI ile karşılaştırma.
- **Benzer İlan Önerisi (kişiselleştirilmiş):** Davranışa göre "bunlar da
  ilginizi çekebilir".
- **Area Insights:** Mahalle bilgisi (okul, suç, demografi) — AI yorumlu.
- **Commute Insights:** İş/okula ulaşım süresi ve yorum.
- **Belge Açıklama (EPC / Floor Plan):** EPC ve kat planını AI'nin sade dille
  açıklaması.

### Değerleme (Valuation)
- **Instant Valuation:** Anlık tahmini değer (sadece "sizi arayacağız" formu değil).
- **AI Valuation Açıklaması:** Rakamın neye dayandığını açıklama / kişiselleştirme.
- **Mortgage / Stamp Duty Calculator:** Hesaplayıcı var mı; sadece rakam mı
  veriyor yoksa **AI finansal yorum/öneri** de var mı?

### İletişim / Lead
- **AI Chat Assistant / Chatbot:** Site geneli veya ilan bazlı sohbet asistanı.
- **Lead Qualification:** Formu herkese aynı mı, yoksa AI ön eleme/önceliklendirme
  yapıyor mu?
- **Otomatik Randevu / Viewing Planlama:** AI ile görüşme/viewing ayarlama.
- **Mesai Dışı Yanıt:** Mesai dışında otomatik yanıt/chatbot var mı, sessizlik mi?

### Teknik / Genel
- **SSR vs CSR:** Sunucuda mı render (Nuxt/Next SSR) yoksa client-side mı?
- **API çağrıları:** Network tab'de Neuron API veya 3. parti servisler görünüyor mu?
- **Mobil davranış:** Filtreler/formlar mobilde kullanılabilir mi?

> Kural: Bir özellik "var" görünse bile **ne kadar iyi** çalıştığını yazın
> (ör. AI chat basit soruları yanıtlıyor ama detayda danışmana yönlendiriyor).
